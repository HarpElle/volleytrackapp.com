# VolleyTrack standalone site

Static marketing and support site for `volleytrackapp.com`.

## Guardrails

- This project is independent of `harpelle.com`; do not change existing VolleyTrack pages or redirects without separate owner approval.
- VolleyTrack is in final release-candidate testing. Store badges remain inactive until public listings are ready.
- Claims and public privacy content must be revalidated against the released app before broad rollout.
